# ShopZone — Amazon-Inspired E-Commerce Website

ShopZone is a responsive Amazon-inspired e-commerce website built with HTML, CSS, and JavaScript. It features product listings, search, category filters, price sorting, wishlist buttons, and an interactive shopping cart with quantity management and dynamic pricing. Easily hosted for free using GitHub Pages.

## Features

- Responsive layout for desktop and mobile
- Product cards with sample prices and ratings
- Search products by name or category
- Filter by Electronics, Home, Fashion, and Books
- Sort products by price
- Add products to the cart, update quantities, and remove items
- Dynamic cart count and subtotal
- Wishlist buttons and demo newsletter signup
- No build tools or installation required

## Files

- `index.html` — website structure
- `style.css` — styling and responsive layout
- `script.js` — search, filters, sorting, wishlist, and cart functionality

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Deploy with GitHub Pages

1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes for GitHub Pages to publish your site. Your URL will look like `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

## Important note

This is a frontend demo using sample product data. It does not include real payments, customer accounts, order processing, or a backend database. ShopZone is an independent demo and is not affiliated with Amazon.
